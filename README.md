# HexAI organisation defaults

The files in this repository apply to every repository in `HexAI-inc` that does not define its own:

- `CONTRIBUTING.md`: how to contribute
- `.github/PULL_REQUEST_TEMPLATE.md`: the pull request template
- `.github/ISSUE_TEMPLATE/`: issue templates for tasks, bugs and decisions

To change a default for one repository only, add a file with the same name and path to that repository.
